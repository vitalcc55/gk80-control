Попытка `go test -race` для Wails desktop в Ubuntu/WSL не собрала пакет из-за отсутствующего `pkg-config`; это не относится к успешной отдельной race-проверке хранилища. `check:pr` относится к frontend и не заменяет Go, процессные и контрактные проверки.
