# Подтверждения первого демонстрационного прохода

Этот журнал фиксирует проверки законченных этапов активного [плана](first-core-demo-plan.md). Проверки выполнялись 29 октября 2026 года на Windows, если явно не указано иное. Они подтверждают только указанную область; полный проход пока не завершён.

| Этап | Команды и наблюдения | Результат и ограничения |
|---|---|---|
| План и согласование | Изучены активные issues и проектные документы, проверен исходный снимок экранов `81565e7`. | План и сообщённое пользователем согласование зафиксированы; это не проверка работающего ядра. |
| Контракт и генерация | `npm run check:quick`, `npm run contract:test`, `npm run contract:check`, Go-тесты схем и предметной границы. | Успешно; frontend: 38 тестов. Схема и сгенерированные типы сами по себе не реализуют операции ядра. |
| Диагностика | `go test ./internal/diagnostics`, `golangci-lint run ./internal/diagnostics/...`; Ubuntu/WSL: `go test -race -count=1 ./internal/diagnostics`. | Успешно для отдельных тестовых writer и очереди; сквозной журнал команды испытания ещё не проверен. |
| Отдельный core и защищённое соединение | `go test -count=1 ./internal/profile ./internal/transport ./internal/core ./cmd/gk80-core`, целевой `golangci-lint`; Ubuntu/WSL: `go test -race -count=1 ./internal/profile ./internal/transport`. | Успешно; проверены отдельный процесс, профиль и защищённый handshake. Испытания и WebSocket не подключены. |
| Desktop и core | `npm run check:quick`, `npm run contract:test`, `npm run contract:check`, Go-тесты desktop/диагностики/контракта, целевой `golangci-lint`, `.\scripts\build-desktop.ps1`; ручная проверка окна и закрытия. | Успешно; frontend: 46 тестов. Окно показало подтверждённую связь, отдельные desktop и core завершились, журнал связал их по идентификатору ядра. Предметный маршрут и SQLite из окна ещё не доступны. |
| Основа SQLite | `go test -count=1 ./internal/storage ./internal/core ./internal/transport ./internal/profile`, `golangci-lint run ./internal/storage/... ./internal/core/...`, `npm run contract:check`, сборка `go build` ядра при `CGO_ENABLED=0`; Ubuntu/WSL: `go test -race -count=1 ./internal/storage`. | Успешно; проверены создание и повторное открытие, атомарность, повторы и отказ записи. Нет ещё сетевых предметных команд, симулятора, измерений и остановки. |
| Завершение диагностики, запуск и HTTP | `go test -count=1 ./internal/core ./internal/diagnostics ./internal/transport ./internal/desktop`, `golangci-lint run ./internal/diagnostics/... ./internal/core/... ./internal/transport/... ./cmd/gk80-core/...`, `npm run contract:check`, `.\scripts\build-desktop.ps1`; два запуска desktop из Проводника с проверкой дочернего процесса и закрытия. Ubuntu/WSL: `go test -race -count=1 ./internal/diagnostics ./internal/core ./internal/transport`. | Успешно: `401` проверен по схеме, неподтверждённое закрытие журнала обнаруживается отдельно от сохранения испытания. Оба запуска на Windows подтвердили связь, отсутствие окна консоли у core и его завершение с кодом 0. Сквозной проход пока не подключён. |
| Состояния и данные SQLite | `go test -count=1 ./internal/storage ./internal/diagnostics ./internal/contract ./internal/core ./internal/transport`, целевой `golangci-lint`, `npm run contract:check`, `npm run check:quick`; Ubuntu/WSL: `go test -race -count=1 ./internal/storage`. | Успешно: проверены миграция v1 с сохранением прежней команды и параметров, WAL/FULL, переходы и аудит, пакеты измерений и восстановление без возобновления. Frontend: 46 тестов. Реальный симулятор, независимая от SQLite остановка и предметные HTTP/экран ещё не подключены. |

Windows race-профиль с C-компилятором не подготовлен. Попытка `go test -race` для Wails desktop в Ubuntu/WSL не собрала пакет из-за отсутствующего `pkg-config`; это не относится к успешной отдельной race-проверке хранилища. `check:pr` относится к frontend и не заменяет Go, процессные и контрактные проверки.
