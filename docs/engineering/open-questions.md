# Открытые инженерные вопросы

Здесь перечислены вопросы, влияющие на проектирование и проверку. Отсутствие ответа не следует заменять вымышленным нормативом. Для демонстрации допустимо отдельное явно обозначенное правило; оно не становится правилом реального стенда.

| Вопрос | Что требуется определить |
|---|---|
| Возможности ПЧ | По документации выбранного устройства и при подключении проверить признак остановки, оставшееся время торможения, остановку без задания времени и сброс ошибки. Действия оператора и момент показа результата уже определены в [сценарии](single-point-test.md). |
| Аварийное давление при измерении | ТЗ §5.2.3 задаёт останов при отклонении более ±5% в течение заданного времени. §5.4 отдельно требует защиту при превышении максимального давления более чем на 10%, а §5.2.5 задаёт аварийную границу перепада на диафрагме. Для основного измерения уточнить применимость первого правила, пределы и выдержку, а для защиты §5.4 — значение максимума и условие срабатывания. Допуск стабилизации к измерению не применяется. |
| Исход повторного подбора | Подтвердить результат истечения 600 секунд при повторном подборе частоты после выхода из диапазона. |
| Потеря ПК или связи с управлением | Окончательная реакция шкафа управления и границы ответственности аппаратной защиты. |
| Недостоверные показания и потеря связи с датчиками | Уточнить допустимый пропуск и момент останова для ДД1 и для обоих датчиков перепада. При потере связи только с ДД2 или ДД3 согласовать, как применить требование останова из §5.4 при наличии исправного второго канала. Принцип переключения при недостоверности показаний и назначение каналов уже заданы в [ТЗ и конспекте измерений](measurement-channels.md). |
| Смена канала в окне расчёта | Согласовать, можно ли объединять пригодные участки ДД2 и ДД3 в одном результате. Точные пороги переключения относятся к пусконаладке согласно §7 ТЗ. |
| Разрежение | Зафиксировать знак, единицы и интерпретацию давления и перепада в контракте и интерфейсе. |
| Параметры воздуха и пригодность тракта | Уточнить источник температуры для плотности, допустимый возраст входных данных и действия при их отсутствии. Рабочий диапазон и погрешность тракта подтвердить по паспортам и на стенде. Остальные источники заданы в [конспекте измерений](measurement-channels.md). |
| Расход, усреднение и качество окна | Согласовать порядок усреднения, получение фактического давления точки по ДД1, покрытие окна и обработку пропусков, недостоверного, нулевого и отрицательного перепада. См. [разбор расхождения разделов ТЗ](leakage-characteristic.md#что-нужно-согласовать-перед-расчётом). |
| Класс герметичности | Для оценки по приложению А ГОСТ Р 71461-2024 подтвердить используемый расход, соответствие ДД1 испытательному перепаду на клапане, численное представление границ и правило учёта округления и погрешности. Условия приведения самого расхода заданы ТЗ. См. [характеристику утечки](leakage-characteristic.md). |
| Два прохода по уровням | После одной точки согласовать измерение нижнего уровня при развороте, итог по двум результатам при Pmax и обработку их расхождения. |
| Инженерные параметры | Определить права на просмотр и изменение настроек. |
| Официальный протокол | Получить форму заказчика и согласовать содержание, печать, экспорт, смысл давления на характеристике и методику временного ряда расхода. |
| Доступ к приборам | Получить подтверждённые модели, карты регистров, конфигурацию связи и настройки для будущего подключения реального оборудования. |
| Публичность технических данных | Отдельно определить, какие характеристики конкретных приборов, размеры и расчёты можно раскрывать; локальные паспорта не публикуются автоматически. |

## Основание

Вопросы собраны по разделам ТЗ о датчиках, расчётах и безопасности и по публичным границам демонстрации. Технические вопросы и вопросы допуска к публикации различаются: ответ на один из них не решает другой.
