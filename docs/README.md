# Документация ГК80

Документация разделена по назначению и доступности:

| Каталог | Содержимое | Доступность |
|---|---|---|
| `private-sources/` | Оригиналы ТЗ, паспортов и расчётов; могут содержать персональные и иные непубличные данные | Только локально; каталог исключён из Git |
| `policies/` | Авторские правила проектирования и оценки интерфейса | Материалы для открытого репозитория |
| `engineering/` | Обезличенные инженерные конспекты: назначение стенда, измерения, сценарий и открытые вопросы | Материалы для открытого репозитория после проверки изменений |

Локальный указатель исходников — `private-sources/INDEX.local.md`. Он и оригиналы не попадают в Git; в другой рабочей копии их наличие нужно проверять отдельно.

## Работа с исходниками

Оригиналы в `private-sources/` доступны только там, где их отдельно разместили: новый clone или worktree их не получает автоматически. Правило Git защищает от обычного случайного добавления, но не от принудительного добавления или публикации копии. Проверяйте состав будущего коммита.

Конспекты не заменяют оригиналы и не являются утверждённой методикой испытаний. В них записаны обезличенные сведения, ранее раскрытые в публичных задачах проекта; неподтверждённые условия помечены отдельно. Перед добавлением сведений из оригиналов проверяйте допустимость публикации. Не переносите имена, подписи, контакты, номера конкретных приборов и сведения из внутренних комментариев. Неопубликованные характеристики оборудования и размеры конкретных изделий требуют отдельного решения о раскрытии.
