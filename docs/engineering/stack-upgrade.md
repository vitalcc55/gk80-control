# Согласованное обновление стека

## Результат и исходная точка

Обновить согласованные зависимости, воспроизводимо получить типы и собрать
desktop/browser с прежним поведением команд, хранения и восстановления.
Приёмка включает существующие автоматические проверки Windows/Linux и отдельные
проходы настоящего Windows/WebView2 и IAB. Наличие совместимых peer-диапазонов
само по себе не подтверждает этот результат.

Исходный `main`: `e0ffb9d4e28b984514774554cdf237dcda47d0c4`, после PR #33.
Локальная основа миграции дополнительно содержит принятое обновление Medeo Sans
`4407ffa`; шрифт сохраняется. Последний полный verify PR #33 относится к прежнему
стеку и не выдаётся за проверку обновлённых зависимостей.

## Границы и сохраняемые решения

- React → тонкий Wails-адаптер → локальные HTTP/JSON и WebSocket → отдельный Go
  core → симулятор/SQLite; предметные правила не переносятся между слоями.
- Node 24.22.2, npm 11.19.1, Go 1.27.3, TypeScript 7.0.2, React 19.3.1,
  jsdom 30.1.3, Playwright 1.64.1 и остальные невыбранные прямые пакеты сохраняются.
- OpenAPI 3.1.2, JSON Schema 2020-12 и YAML v3 сохраняются. Схема БД, точные
  исходные команды, идемпотентность, Stop, lease, сроки и аудит не меняются.
- `modernc.org/libc` остаётся 1.79.0; косвенные библиотеки обновляются только
  по требованиям выбранных владельцев. Независимого повышения kin-openapi нет.
- Строгость типов, правила lint, проверки generated и критерии приёмки
  не ослабляются. Исторические отчёты и разовые исключения остаются историческими.
- Новые функции, внедрение Zustand, переделка UI, реальные устройства, упаковка,
  новый build framework и исправление U01 не входят в миграцию.
- Существенная несовместимость, требующая изменения этих контрактов, — условие
  остановки для отдельного решения. Защита Windows не изменяется и не обходится.

## Подтверждения

- Frontend: `check:quick`, затем итоговый `check:pr`; все три входа сборки,
  существующие проверки графика, шрифта и пяти экранов. Чистая установка из lock.
- Go: существующие contract/storage/demo/core/transport/browser тесты, включая
  rollback/audit/context/reopen, vet/lint и согласованность модулей. Это не отдельное
  доказательство каждой новой внутренней ветви стороннего SQLite-драйвера.
- Генерация: `contract:generate`, `contract:check`, `contract:test`; 14 файлов,
  два сервиса, 24 метода, три события, обязательные поля и отсутствие `any`.
- Host: portable/native, отрицательные runner-сценарии и отдельный корневой
  `go test -tags=desktopapp .`. Native-профиль desktop не заменяет корневой тест.
- Linux: отдельная установка/сборка frontend и portable host с race в Ubuntu/WSL;
  GUI не требуется. Инструментация дочернего core указывается отдельно.
- Windows/WebView2: холодный запуск, Create/Start/Confirm, показания, Stop,
  сохранение, закрытие, повторное открытие. Доставка через fallback сама по себе
  не доказывает конкретное Wails-событие.
- IAB: настоящий demo-core/SQLite, refresh без повторных команд, потеря core,
  достоверность состояния и завершение собственных процессов. Fixtures отдельно.
- Старая история: копия закрытого существующего demo-профиля; чтение завершённых
  и прерванных записей. Оригиналы не изменяются и не используются для новых опытов.

## Фактические результаты

До установки нового дерева: Windows 11 x64, Node 24.22.2/npm 11.19.1,
Go 1.27.3, Wails 3.0.0, golangci-lint 2.15.0. Ubuntu/WSL:
Linux 6.6.87.2, Node 24.22.2/npm 11.19.1, Go 1.27.3, GCC 13.3.
Эти сведения относятся к исходному окружению; проверки обновлённых частей ниже.

### Frontend

Семь выбранных прямых пакетов установлены штатным `npm install` без `--force`,
`--legacy-peer-deps` и изменения npm/Node. Прочие прямые версии, в том числе
Wails runtime 3.0.0 и jsdom 30.1.3, сохранены. В lock-файле 264 записи вместо 272:
изменились 84 пути, включая платформенные варианты и устранение вложенных копий
Lightning CSS/magic-string. Изменения соответствуют владельцам Vite, Tailwind,
Vitest и Biome; отдельного обновления косвенных пакетов не выполнялось.

Windows `npm run check:quick` прошёл: строгая проверка типов, Biome без
предупреждений и 522 теста в 16 файлах на Vitest 5.1.0. Рукописные компоненты,
тесты и их ожидания не менялись. Два независимых read-only review не обнаружили
конкретных замечаний. После review прошли `check:pr` (522 Vitest и 37 Playwright,
типы/lint/fixture-сборка), `build:desktop` и `build:browser`. Последние две команды
здесь подтверждают frontend-входы, не сборку/запуск нативной оболочки. Чистая
установка окончательного lock и Windows/Linux/IAB остаются итоговыми проверками.

Сырые результаты, графы и изолированные demo-профили:
`.tmp/.codex/stack-upgrade/`. Итоговые результаты и ограничения дополняются
после соответствующих проверок; отсутствие запуска не считается PASS.
