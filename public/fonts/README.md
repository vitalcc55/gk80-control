# Medeo Sans

В приложение включён оригинальный variable WOFF2 Medeo Sans обычного начертания,
с весами 100–900. Он подключается локально через `src/index.css` и не требует
сети при работе приложения.

- Выпуск: **Medeo v1.0.0**, версия внутри шрифта **1.000**.
- Источник: [официальный релиз](https://github.com/DNFDEVS/medeo-font/releases/tag/v1.0.0).
- Файл в релизном архиве: `fonts/MedeoSans/webfonts/MedeoSansVariable.woff2`.
- Тот же файл опубликован в `medeo-font@1.0.0`:
  `dist/fonts/medeo-sans/MedeoSansVariable.woff2`.
- SHA-256 `MedeoSansVariable.woff2`:
  `0631d1c0c8174a8a5b08ce3aba44cab951bdb9054c94c58103b1e00689eec970`.
- Лицензия: SIL Open Font License 1.1; оригинальный текст и сведения об авторах
  сохранены в `OFL.txt` из того же выпуска.

Отдельная npm-зависимость для этого способа подключения не нужна. При следующем
обновлении заменить шрифт и лицензию из одного официального выпуска, обновить
версию и контрольную сумму здесь. Проверить загрузку шрифта и компоновку экранов
на 1366×768 и 1920×1080, затем выполнить `npm run check:quick` и
`npm run check:pr`. Наличие нового файла не подтверждает нативную Windows-приёмку.
